# CloudKinshuk – Developer Portfolio 🚀

A modern, responsive **developer portfolio website** built with **Next.js (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. This project is designed to showcase skills, projects, and experience with a clean UI, smooth animations, and production‑ready architecture.

Live example: **[https://cloudkinshuk.in](https://cloudkinshuk.in)** (replace with your deployed URL if forked)

---

## ✨ Features

* ⚡ **Next.js 16 (App Router)** for high performance and SEO
* 🎨 **Tailwind CSS 4** for utility‑first, scalable styling
* 🧩 **TypeScript** for type safety and maintainability
* 🎞 **Framer Motion** for smooth, modern animations
* 📱 **Fully responsive** (mobile, tablet, desktop)
* 🧠 **Reusable components** and clean folder structure
* 🚀 **Production‑ready** and easily deployable on Vercel

---

## 🛠 Tech Stack

* **Framework:** Next.js 16.1.6
* **UI Library:** React 19.2.3
* **Language:** TypeScript 5
* **Styling:** Tailwind CSS 4, tailwindcss-animate
* **Animations:** Framer Motion
* **Icons:** lucide-react, react-icons
* **HTTP Client:** Axios
* **Linting:** ESLint (Next.js config)

## 🚀 Getting Started (Local Setup)

Follow these steps to run the project locally.

### 1️⃣ Prerequisites

Make sure you have the following installed:

* **Node.js** ≥ 18
* **npm / yarn / pnpm / bun**

Check versions:

```bash
node -v
npm -v
```

---

### 2️⃣ Fork the Repository

1. Open the GitHub repository
2. Click the **Fork** button (top‑right)
3. This creates a copy under your GitHub account

---

### 3️⃣ Clone the Forked Repository

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

---

### 4️⃣ Install Dependencies

Using npm:

```bash
npm install
```

Or with other package managers:

```bash
yarn install
pnpm install
bun install
```

---

### 5️⃣ Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:3000
```

The site will auto‑reload as you edit files.

---

## 🧑‍💻 Customizing for Your Own Portfolio

After cloning, you can easily personalize it:

### 🔹 Update Content

* Edit `app/page.tsx` – main landing content
* Update components inside `components/`
* Replace images and assets in `public/`

### 🔹 Update Metadata & SEO

Modify `app/layout.tsx`:

* Title
* Description
* Open Graph tags

### 🔹 Styling

* Tailwind styles: `globals.css`
* Tailwind config: `tailwind.config.ts`

---

## 📦 Build for Production

```bash
npm run build
npm run start
```

This creates an optimized production build.

---

## ☁️ Deployment (Vercel – Recommended)

```bash
You can use AWS ( Amazon Web Services) , Azure , GCP any cloud services you prefer. For mine i have deployed it on aws as it my prefered cloud platform. 

Thank You.

```

1. Push your forked repo to GitHub
2. Go to **[https://vercel.com](https://vercel.com)**
3. Click **New Project**
4. Import your repository
5. Select **Next.js** (auto‑detected)
6. Click **Deploy** 🚀

Your portfolio will be live in minutes.
